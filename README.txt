HELEN & SONS WEBSITE - QUICK START
1. Extract the ZIP file.
2. Open Visual Studio Code.
3. Choose File > Open Folder and select helensons-website.
4. Open index.html in a browser (or install VS Code Live Server extension and click Go Live).
5. Edit text in index.html, styling in style.css, interactions in script.js.
IMPORTANT: This is a new demo site, not a modification of your live website. The form opens an email draft and does not send to a server. The Dubai background image is included locally. Fonts load from Google Fonts; internet access is needed for those fonts. Review content and obtain approval before publishing.
